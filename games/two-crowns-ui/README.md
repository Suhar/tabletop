# The Two Crowns 1874 UI

`@tabletop/two-crowns-ui` is the Svelte Game Client for The Two Crowns 1874. It consumes
`@tabletop/two-crowns`, shared presentation from `@tabletop/18xx-ui`, and the Game Client support.
It uses the generic boardless map; there is no board artwork yet.

Run the hotseat development harness with `pnpm --filter @tabletop/two-crowns-ui dev`
(port 4195). The 18xx Playground also hosts the title at `/table` under "The Two Crowns 1874".
